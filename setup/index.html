Setup for Code

GR00T-N1.5

First, clone the repository.

git clone https://github.com/NVIDIA/Isaac-GR00T
cd Isaac-GR00T

Then create a conda environment for it.

conda create -n gr00t python=3.10
conda activate gr00t

I installed the nightly build of PyTorch for CUDA 12.8, because my workstation gpu architecture is sm120. 

pip3 install --pre torch torchvision --index-url https://download.pytorch.org/whl/nightly/cu128

Then I install pytorch3d next.

export TORCH_CUDA_ARCH_LIST="12.0"
pip install --no-build-isolation "git+https://github.com/facebookresearch/pytorch3d.git"

The rest of the dependencies follow.

pip install --upgrade setuptools
pip install -e .[base] --no-deps
pip install --no-build-isolation flash-attn

Troubleshooting

Error: raise InvalidSchemaError from e pydantic._internal._generate_schema.InvalidSchemaError Solution: Ensure NumPy is compatabile with numpydantic and Pydantic. I did the following because I had NumPy v1.26.4.

# first check your NumPy version
python -c "import numpy; print(numpy.__version__)"

pip install pydantic
pip install --upgrade numpydantic
cd ~/IsaacGR00T 
pip install -e .[base] --no-deps
